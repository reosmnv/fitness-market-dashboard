# Конкуренты: открытия, акции, отзывы (версия 2, реальные данные)

Дашборд маркетолога фитнес-сети: что делают 8 сетей-конкурентов (DDX Fitness, Spirit Fitness, XFIT, Фитнес С.С.С.Р., UFC GYM, Территория Фитнеса, Crocus Fitness, Encore Fitness) в Москве, МО, Санкт-Петербурге и Сочи рядом с нашими 42 клубами.

**Только реальные данные.** У каждой записи есть ссылка на источник и дата сбора. Если данных нет, блок пустой. Версия 1 на демо-данных лежит в [`v1/`](v1/).

| Вкладка | Что показывает |
|---|---|
| События по клубам | Клубы конкурентов в анонсе, предпродаже, недавно открытые и закрытые; ближайший наш клуб, пешие минуты и км |
| Акции | Действующие акции с сайтов и из Telegram-каналов сетей: механика, тип, срок, города, баннер |
| Клубы конкурентов | Все клубы 8 сетей в нашей географии с расстоянием до ближайшего нашего |
| Карточки конкурентов | Модель продаж, условия, динамика, новости, отзывы (что хвалят и ругают, с цитатами) |
| Сезонный календарь | Рынок по месяцам, только по первоисточникам (НФС, ФНС) |
| Источники и методика | Что собрано, какие площадки доступны, как считается |

Фильтры: город, сеть, наш клуб. Срез передаётся ссылкой: `?city=spb&chain=ddx#events`.

## Данные

Всё на экране берётся из `data/data.json`. Его собирают скрипты вне этого репозитория (папка проекта `fitness-dashboard-real/collect`, `build.py`). Источники:

- сайты сетей: списки клубов (JSON внутри страниц у DDX, XFIT, Spirit, Encore, Tilda-сетей), страницы акций;
- Telegram-каналы сетей (`t.me/s/…`, посты за 60 дней, разбор моделью);
- отзывы: Яндекс Карты, irecommend (2ГИС и Отзовик на момент сбора недоступны);
- координаты: OpenStreetMap (Nominatim), пешие маршруты: Valhalla (FOSSGIS).

Сбор 06.11.2026 первый. Изменения статусов клубов появятся со следующего сбора.
