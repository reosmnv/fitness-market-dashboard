# Конкуренты и рынок: дашборд маркетолога фитнес-сети

Макет дашборда для маркетолога сети фитнес-клубов: что делают конкуренты (DDX Fitness, Spirit Fitness, XFIT, Фитнес СССР, UFC GYM, Территория Фитнеса, Crocus Fitness, Encore Fitness) в Москве, Санкт-Петербурге и Сочи и что с этим делать на этой неделе.

**Статус: макет на демо-данных.** Записи с меткой ДЕМО вымышлены и показывают формат. Записи с меткой ФАКТ взяты из ресерча 31.10.2026, источник виден при наведении. «Наша сеть» и её клубы вымышлены.

## Что где лежит

| Вкладка | На какой вопрос отвечает | Когда открывать |
|---|---|---|
| 1. Неделя | Что изменилось рядом с нашими клубами и что делаю | Каждый понедельник, 10 минут |
| 2. Цены и акции | Где мы по цене и кто атакует акциями | Изменения: неделя. Сводка: квартал |
| 3. Зоны клубов | Кто вокруг каждого нашего клуба | События: неделя. Плотность: квартал |
| 4. Карточки конкурентов | Что за игрок и куда он движется | Раз в месяц |
| 5. Мы и рынок | Просели мы или весь рынок, сработала ли защита | Раз в месяц |
| 6. Сезон и правила | К чему готовиться в ближайшие 3 месяца | Перед сезоном |
| Справка | Метки, методика индекса, словарь, алерты, открытые вопросы | Когда что-то непонятно |

Фильтры над вкладками: город, сегмент конкурентов, наш клуб, неделя событий. Срез можно передать ссылкой: `?city=sochi`, `?segment=premium`, `?club=msk-mitino`, вкладка через `#prices`, `#zones` и т.д.

## Файлы

```
index.html          каркас страницы
assets/styles.css   оформление, светлая и тёмная темы
assets/app.js       логика: вкладки, фильтры, расчёт индекса цены, графики
data/data.json      все данные дашборда
```

## Как обновлять данные

Всё, что видно на экране, берётся из `data/data.json`. Скрипт сбора будет перезаписывать этот файл после каждого прогона, код при этом менять не нужно.

Основные разделы файла:

| Раздел | Что внутри |
|---|---|
| `events` | События: неделя, сеть, город, клуб, тип, уровень, сигнал, «что случилось / что значит / что делаем» |
| `promos` | Реестр акций: механика, охват, глубина, возраст в неделях, признак trade-in |
| `prices` | Цены по сетям и городам: первый платёж, 3 и 12 месяцев со взносом, взнос, статус «акция/база» |
| `zones` | Конкуренты вокруг каждого нашего клуба: минуты доезда, статус, новый ли за квартал |
| `chains` | Карточки сетей с источниками |
| `marketFacts`, `marketLine` | Рыночные цифры с источником и надёжностью |
| `regulation`, `season`, `milestones` | Регуляторный и сезонный календари |
| `ownClubs`, `protected`, `ownVsMarket`, `churnToCompetitor`, `responses` | Наши внутренние данные (в макете демо) |

У каждой записи есть признак `demo`: `true` даёт метку ДЕМО, `false` даёт метку ФАКТ с источником из `src`.

## Методика индекса цены

Индекс = наша полная сумма за 12 месяцев со взносом / медиана той же суммы у сетей нашего сегмента в городе × 100. Больше 100: мы дороже. Если в сегменте меньше двух предложений, индекс не считается. Сети без публичных цен в индекс не входят.

## Запуск локально

```
python3 -m http.server 8000
```

Затем открыть http://localhost:8000. С диска (file://) данные не загрузятся: браузер блокирует чтение файла.
